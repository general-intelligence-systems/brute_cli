# brute_cli

Command-line interface for the [Brute](https://github.com/general-intelligence-systems/brute) coding agent.

## Usage

Please see the [project documentation](https://general-intelligence-systems.github.io/brute_cli/) for more details.

  - [Getting Started](https://general-intelligence-systems.github.io/brute_cli/guides/getting-started/index) - This guide walks you through installing brute_cli and running your first prompt.

  - [Interactive Mode](https://general-intelligence-systems.github.io/brute_cli/guides/interactive-mode/index) - Run brute without arguments to enter interactive mode for multi-turn conversations.

  - [Sessions](https://general-intelligence-systems.github.io/brute_cli/guides/sessions/index) - Resume previous conversations by session ID.

  - [Piped Input](https://general-intelligence-systems.github.io/brute_cli/guides/piped-input/index) - Pipe text into brute for non-interactive use.

## Dependencies

- [brute](https://github.com/general-intelligence-systems/brute) -- core agent library
- [brute_flow](https://github.com/general-intelligence-systems/brute_flow) -- BPMN flow engine (optional, loaded if available)
